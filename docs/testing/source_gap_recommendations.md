## Agent-by-agent source and code actions

**Scout:** Existing SEC EDGAR/issuer-IR and allowed exchange/company disclosure
actions are the right source types. First inspect their actual availability,
entity identifiers, request settings and returned document URLs. S3's StockTitan
filing mirror is useful context but does not prove an original regulator response.
Compare native captured amounts and period/units with actual original tables.
Do not infer a ticker for ambiguous companies, silently license exchange data,
or discard all history to manufacture a clean current result. S1/S3 already have
enough displayed text; selection, authority and period adjudication are the gaps.

**BrandShield:** B1's corrected WWD incident passage is usable bounded reporting;
B3's Free Press Journal/CNBC-TV18 paragraphs preserve allegations and named
officials. Follow observed original authority/manufacturer references if allowed,
not a generic FTC index as though it described the case. Dyson and Apple need
resolved article leads: their current failures happen before semantic passage
selection. Keep awareness/warnings, claims, enforcement and convictions distinct.
The recall-word fix is demonstrated offline; it does not prove fresh additional
incident recall. Raw WWD volume is not a reason to prefer it over an available
original case record.

**Trending:** T2 proves that an ordinary entertainment query can acquire genuine
current articles without supplied URLs. Its publisher is bdnews24, and 239 words
reach the browser in recovered-pool replay. Preserve the missing original native
response limitation. For semiconductor and recycling questions, inspect the
existing topic/source plans and current feed/query responses before expanding
another catalog. A fresh index date is not publication; date-less articles and
future timestamps remain rejected. T4's current report discusses an old event:
preserve both clocks. Original sports/production/technical announcements and
independent reporting serve different roles. Public attention/virality still
requires repeated comparable observations, not more words or sites.

**Personal Watch:** The plural false-quotation router is fixed, but has no fresh
P2/P4 discovery proof. The strongest remaining defect is question fulfilment:
ordinary interviews/lawsuit coverage may be relevant to a person without
answering impersonation or fabricated endorsement. Retain exact text and quote
context; do not upgrade a reported quotation to authenticated speech. P3/P4 have
no article bodies, so wider passage limits cannot help them. Prioritize bounded
resolution of actual statement/fact-check article URLs and observed primary
recordings/official channels. P1's historical material remains labeled by date.

## API/model calls that would have diagnostic value

Use an existing permitted discovery/API route when it can supply a missing
document identifier or observed article URL. Existing filing/issuer APIs can
provide accession/period identity, while permitted topic feeds and discovery
adapters can improve freshness. A search index or API metadata record still
needs appropriate native article/document acquisition before it becomes evidence.

Optional Gemini advice should receive the narrow missing task and compact
observed failure reasons, and return one validated query/source hint within the
existing shared policy. It must not invent article URLs, bodies, dates, incidents
or a desired verdict. These sixteen cases consumed five new reservations, with
two successful suggestions and three timeouts; model availability did not solve
the primary-source and exact-task gaps. Keep real usage and unknown timeout
usage distinct. Raising paid/model quotas is not required by this plan.

## Verification before any further live request

Reuse the saved genuine bodies, metadata and denial responses. Assert exact
task acceptance, wrong-period/background separation, plural/conditional abuse
language, candidate choices, deadlines, rights restrictions and source-to-report
identity. Preserve the new duplicate-ordering positive/negative controls and
Unicode-safe audit capture. No 401/403/429 reader fallback, SSRF/DNS validation
skip, authorization expansion or frozen-fixture rewrite is acceptable.

After implementation, define a **new small case/request budget** with a specific
diagnostic purpose. Start with a weak statement/identity task and one current
financial primary-document task; do not repeat all sixteen to chase a word
threshold. Each should retain the exact native response, read ledger, admission
observations, source bodies where permitted, code fingerprint and rendered
passages. Offline regressions and this report do not authorize deployment.
