// SOURCE LINEAGE DE-DUPLICATION

Syndication Clustering

When ten media outlets publish identical text originated from a single wire bulletin (AP, Reuters, PR Newswire), naïve consensus models treat them as 10 independent confirmations. Aegis extracts root domain lineage to collapse wire syndications into a single origin node.

// TRIMMED CONSENSUS (W-MSR INVARIANT)

Outlier-Resistant Score Aggregation

Inspired by the Weighted Mean-Subsequence-Reduced (W-MSR) algorithm from distributed fault tolerance, Aegis prunes extreme score outliers before calculating weighted consensus to avoid sycophantic or degraded vector distortions.
