Changelog

Version history and release notes for the Aegis Protocol platform.

v3.7.0 October 2026 LATEST
Multi-Intent Investigation Routing, Provenance Hardening & Runtime Integrity Pass
Features & Architecture
  • Universal Intent Switcher: Replaced static buttons with a 5-category intent bar (Verify Claim / Trending / Company Scout / BrandShield / Personal Watch) with cross-agent URL query prefill.
  • Runtime Truth & Integrity Audit: Completely eliminated synthetic fallback evidence generators. When upstream providers or backend APIs fail, pages render genuine cached snapshots or explicit, honest unavailable notices.
  • Clear AI Synthesis vs Retrieved Evidence Demarcation: Direct Gemini client fallbacks are explicitly classified as AI_SYNTHESIS rather than retrieved evidence, preventing manufactured source citations.
  • Authoritative Identity Consolidation: Harmonized protocol version 3.7.0 across backend, API docs, telemetry, navigation, and frontend page footers.
  • Dedicated 404 Route & SPA Routing Fix: Introduced standalone forensic 404 error page and removed catch-all route masks.
v3.6.0 September 2026
Domain Agents & Layered Evidence Presentation
Features & Architecture
  • Trending Agent: Multi-channel trend discovery with velocity tracking, evidence normalization, and syndication clustering.
  • BrandShield Agent: Brand protection and threat classification (counterfeits, scams, review manipulation, impersonation) with structured findings.
  • Personal Watch Agent: Public signal monitoring, impersonation detection, and claim attribution.
  • 3-Tier Presentation Structure: Restructured agent interfaces to display answers first, evidence second, and technical details in inspectable panels.
  • Expanded Test Suite: Automated unit, integration, and security tests passing with zero regressions.
v3.2.0 September 2026
Evidence Analysis & Research Simulation Tools
Features & Architecture
  • Analysis Pipeline (submit.html): Combined claim submission with Zipf-Mandelbrot rank-frequency analysis, Hawkes diffusion simulation, and consensus filtering.
  • Diffusion Simulation Canvas: Interactive 2D Hawkes self-excitation canvas displaying information cascade spread and verification beacons.
  • Zipf-Mandelbrot Token Regression: Power-law log-log scatter plot detecting vocabulary distribution characteristics ($R^2$, token entropy, type-token ratio).
  • Consensus Matrix ($F=1$): W-MSR outlier rejection table pruning adversarial votes in real-time.
  • UI Polish & Consistency: Standardized contrast, interactive focus states, typography hierarchy, and cleaned presentation copy across all pages.
Fixes & Upgrades
  • Fixed character encodings and removed legacy cursor:none across all sub-agent pages.
  • Ensured dynamic localhost backend resolution across dashboard.js, status.html, and agent tools.
  • Unified global navigation with aegis-nav.js and standardized footer architecture.
